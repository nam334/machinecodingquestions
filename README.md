# Frontend Machine Coding Questions 💻

A collection of real-world frontend machine coding interview questions solved using React.js, with a strong emphasis on reusable UI components, accessibility, and performance.

## 💡 What’s Inside

- ✅ Accordion Component
- ✅ Modal with backdrop and escape support
- ✅ Infinite Scrolling List
- ✅ Custom Dropdown
- ✅ Todo App with LocalStorage
- ✅ Tabbed Navigation
- ✅ Progress Bar
- ✅ Sketchboard-like freehand tool
- ...and more!

## 🧠 Key Focus Areas

- Component Reusability
- Controlled/Uncontrolled Inputs
- State Management Patterns
- Accessibility (ARIA roles, keyboard navigation)
- Performance Optimization (debouncing, memoization)
- Testing Edge Cases

## 🛠 Tech Stack

- React.js
- JavaScript (ES6+)
- SCSS / CSS Modules
- LocalStorage
- Context API / Hooks
