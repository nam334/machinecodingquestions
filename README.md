## 🔧 Features

- ✅ Accordion Component  
- ✅ Modal with backdrop and escape support  
- ✅ Infinite Scrolling List  
- ✅ Custom Dropdown  
- ✅ Todo App with LocalStorage  
- ✅ Tabbed Navigation  
- ✅ Progress Bar  
- ✅ Sketchboard-like freehand tool  
- ...and more!

---

## ✅ Built-In

- ♻️ Reusable and modular component structure  
- 🧪 Testable logic with edge case handling  
- 🕹️ Keyboard navigable UI elements  
- ⚙️ State handling with both controlled and uncontrolled approaches  
- 🎨 Theming and style customization with SCSS  
- 🧠 Performance-aware implementations (debounce, lazy load)  
- 🗃️ LocalStorage-based persistence where applicable  
- 🧼 Graceful fallback for unsupported scenarios
